FLASHUP — ENQUÊTE SNT (SITE STATIQUE)
====================================
1. Créer un dépôt GitHub public nommé « flashup ».
2. Ajouter à la RACINE du dépôt les fichiers index.html, style.css, script.js, donnees.json, transmission.xml.
3. Dans Settings > Pages, sélectionner « Deploy from a branch », branche « main », dossier « / (root) », puis Save.
4. Attendre la publication. Adresse habituelle : https://VOTRE-PSEUDO.github.io/flashup/
5. Ouvrir cette adresse sur un téléphone et vérifier les cinq indices.
6. Créer UN QR code à partir de cette adresse définitive (pas avant), puis l'imprimer sur le sujet papier.

IMPORTANT :
- Le site fonctionne sans serveur applicatif, sans collecte volontaire d'informations personnelles et sans outil d'analyse.
- Le clic et son journal sont simulés localement. Le JSON et le XML sont des exemples statiques et fictifs.
- GitHub, comme tout hébergeur, peut traiter des journaux techniques (ex. adresses IP) liés à l'accès au site.
- Aucune donnée réelle d'élève ne doit être saisie dans l'enquête.
- Le site requiert Internet sur les téléphones. Prévoir une copie papier des indices si la connexion est indisponible.
- Si GitHub Pages n'est pas accessible depuis les téléphones, vérifier le dépôt public, l'URL et le paramétrage Pages.
